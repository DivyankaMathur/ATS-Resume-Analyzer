ATS Resume Analyzer

Overview

This project is an AI-powered ATS (Applicant Tracking System) Resume Analyzer that evaluates resumes based on job descriptions using Google's Gemini API and Natural Language Processing techniques.

Features

* Resume upload and analysis
* Job description matching
* ATS score generation
* Resume feedback and suggestions
* Keyword extraction using AI
* Interactive user interface

Technologies Used

* Python
* Streamlit
* Google Gemini API
* NLP
* PyPDF2
* Pandas

Installation

pip install -r requirements.txt

Run the Project

streamlit run app.py

Project Structure

ATS-Resume-Analyzer/
│
├── app.py

API Configuration

Create a `.env` file and add your Gemini API key:

GOOGLE_API_KEY=your_api_key_here
